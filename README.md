# Emacs-Oriented Custom Mechanical Keyboard

A custom mechanical keyboard project designed for Emacs, programming, CAD applications, and everyday productivity.

**Status: Work in Progress — Layout Design Stage**

## Overview

I'm a mechanical engineer and currently use an **HHKB Professional JP** as my main keyboard.

While I appreciate its compact design and typing experience, I sometimes find its layout inconvenient when switching between programming, CAD software, spreadsheets, and general desktop tasks.

I'm also an **Emacs beginner**, and I'm interested in exploring how keyboard layout and ergonomics can improve a keyboard-driven workflow.

This project is my attempt to design a keyboard that combines the advantages of compact keyboards with the flexibility needed for different applications.

The layout is still experimental, and community feedback is welcome.

### Key Features

- QWERTY-based typing layout
- Dual Ctrl and Meta (Alt) keys
- Dual Space keys
- Programmable Fn layer for F1–F12
- Dedicated Terminal key
- Dedicated Print Screen / SysRq key
- Dedicated Insert key
- NUM layer for numeric input
- Experimental single-row arrow-key arrangement
- Customizable key mappings for Windows and Linux

Some key assignments, including NUM, TOP, and Fn behavior, are still under consideration.

## Design Goals

1. Improve Ctrl and Meta accessibility for Emacs.
2. Reduce unnecessary hand movement.
3. Support programming and terminal workflows.
4. Maintain compatibility with CAD and spreadsheet applications.
5. Provide flexible key layers without excessive complexity.
6. Support both Windows and Linux.
